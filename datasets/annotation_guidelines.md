# Annotation Guidelines: Thai Cyberbullying (ปกติ / ดูหมิ่น / หมิ่นประมาท)

ใช้กำหนด label ของทุกข้อความใน dataset ให้ตัดสินเหมือนกันทุกครั้ง

> ระบบนี้มีไว้ **คัดกรองความเสี่ยงเบื้องต้น** เท่านั้น label "หมิ่นประมาท" หมายถึง "ลักษณะข้อความเข้าข่าย" ตามเกณฑ์ของโครงงาน ไม่ใช่การวินิจฉัยว่าผิดกฎหมายจริง

## 1. Label

| id | label | ความหมาย | ตัวอย่าง |
|---|---|---|---|
| 0 | `normal` ปกติ | ไม่โจมตีบุคคล หรือบ่นเรื่องสินค้า/บริการ/สถานการณ์ | "เน็ตห่วยมาก", "แม่งร้อนสัส", "นโยบายนี้ไม่เวิร์ค" |
| 1 | `insult` ดูหมิ่น (ป.อาญา ม.393) | ด่า เหยียด ดูถูกบุคคลหรือกลุ่มคน **เป็นความเห็นหรือคำด่า** ไม่ได้อ้างว่าเกิดเหตุการณ์จริง | "มึงโง่เหมือนควาย", "อีตุ๊ดน่าขยะแขยง", "พวกพม่ามันเลว" |
| 2 | `defamation` หมิ่นประมาท (ม.326/328) | **ระบุตัวบุคคล/องค์กรได้** และ **กล่าวหาว่าทำการกระทำที่เสียหาย** ในแบบที่ฟังเหมือนข้อเท็จจริง (ใช้คำสุภาพก็นับ) | "@somchai โกงเงินบริษัทไป 2 ล้าน", "ครูคนนี้แอบมีเมียน้อย", "อิตุ๊ดนี่โกงกูพันเก้า" |

## 2. ผังการตัดสิน

```
1. ข้อความโจมตี "คน" (บุคคล / กลุ่ม / องค์กร) ไหม?
       └─ ไม่ ─────────────────────────────────────► 0 normal
       └─ ใช่
2. ระบุตัวได้ไหม? (ชื่อ, @mention, "ครูคนนี้", "แฟนกู", "ร้านนี้", ชื่อบริษัท/พรรค)
       └─ ไม่ (กลุ่มกว้าง ๆ เช่น "คนไทย", "พม่า", "ตำรวจทั้งหมด") ─► 1 insult
       └─ ใช่
3. มีการกล่าวหาการกระทำที่พิสูจน์จริง/เท็จได้ และทำให้เสียชื่อเสียงไหม?
   (โกง ขโมย ยักยอก ติดยา ติดคุก มีชู้/นอกใจ รับส่วย/สินบน หลอกเงิน ปลอม ทำร้ายร่างกาย ฯลฯ)
       └─ ไม่ (แค่ด่าลักษณะนิสัย: "มันเลว", "ตอแหล", "ขี้โกง" ลอย ๆ) ─► 1 insult
       └─ ใช่ ──────────────────────────────────────► 2 defamation
```

## 3. กรณีที่ตัดสินยาก

| กรณี | label | เหตุผล |
|---|---|---|
| คำหยาบที่ไม่ได้ด่าใคร เช่น "แม่งร้อนสัส", "ชิบหายแล้วการบ้าน" | 0 | ไม่มีเป้าหมาย |
| "กู/มึง" ที่เพื่อนคุยกันปกติ | 0 | คำหยาบอย่างเดียวไม่นับว่าดูหมิ่น |
| ด่า + กล่าวหาในข้อความเดียว เช่น "ไอ้ควาย @x มันโกงเงินพวกเรา" | 2 | ให้คลาสที่หนักกว่าชนะ |
| ข่าวลือหรือคำถาม เช่น "ได้ยินมาว่า X ติดยาจริงไหม" | 2 | การตั้งคำถามก็ยังเป็นการใส่ความ |
| "ตอแหล", "ขี้โกง", "ชาติชู้" ที่ใช้เป็นคำด่า | 1 | เป็นคำด่า ไม่ได้ระบุว่าทำอะไรเมื่อไหร่ |
| กล่าวหาชาติหรือเชื้อชาติ เช่น "มาเลโกงซีเกมส์", "พม่าขี้ขโมย" | 1 | เป้าหมายเป็นกลุ่มกว้าง ระบุตัวบุคคลไม่ได้ |
| กล่าวหาบุคคลสาธารณะที่ระบุชื่อ เช่น "ลุงตู่โกงเลือกตั้ง" | 2 | ระบุตัวได้ + กล่าวหาการกระทำ |
| กล่าวหาหน่วยงานที่ระบุได้ เช่น "ตำรวจโรงพักนี้รับส่วย", "รพ.X ปลอมเวชระเบียน" | 2 | องค์กรระบุตัวได้ |
| วิจารณ์นโยบายหรือผลงาน เช่น "นโยบายนี้ห่วย" | 0 | ไม่ได้โจมตีบุคคล |
| ข้อความที่มีคำกล่าวหาแต่เป็นการแก้ต่าง เช่น "กูไม่ได้โกง" | ตามเนื้อหาส่วนอื่น | ไม่ได้กล่าวหาใคร |
| เล่าเรื่องสมมติ, เนื้อเรื่องละคร, มุก (เช่น "มดขโมยขนม") | 0 | ไม่ใช่การกล่าวหาบุคคลจริง |
| สแปมโฆษณาหรือสแปมหนังโป๊ | ลบทิ้ง | ไม่ใช่ข้อมูลของโจทย์นี้ |

## 4. วิธีที่ใช้ติด label ในรอบนี้

1. **ปกติ / ดูหมิ่น**: ใช้ label เดิมของ dataset ที่เป็นเรื่อง toxic/hate/bully โดยแปลง `neg` → 1 และ `neu`/`pos` → 0
   - ThaiToxicityTweet (dataset2), HateThaiSent (dataset3), ThaiCyberbullyingLGBT (dataset5)
   - Wisesight (dataset1) ใช้เฉพาะ `neu`/`pos` เป็นคลาสปกติ (สุ่มมา 4,000 ข้อความ) เพราะ `neg` ของ Wisesight แปลว่าอารมณ์ลบ ไม่ได้แปลว่าดูหมิ่น
2. **หมิ่นประมาท**: ไม่มี dataset สาธารณะที่มี label นี้ จึงทำแบบนี้
   - กรองข้อความที่มีคำกล่าวหา (โกง ขโมย ติดยา เมียน้อย ส่วย หลอก หนีคดี ฯลฯ) และมีเป้าหมาย (@ ชื่อ อี/ไอ้ ครู ตำรวจ ร้าน ฯลฯ) ได้ 585 ข้อความ
   - อ่านทีละข้อความตามผังข้อ 2 (รวม 966 ข้อความใน 4 รอบ) ได้ข้อความหมิ่นประมาทจริง **103 ข้อความ** บันทึกไว้ใน `annotation/manual_labels.csv`
   - เพิ่มตัวอย่างสังเคราะห์ 300 ข้อความจาก template ที่ใช้ชื่อสมมติ (`annotation/synthetic_defamation.csv`) โดยใส่เฉพาะในชุด **train** เพื่อให้การวัดผลยังทำบนข้อมูลจริงทั้งหมด

## 5. ข้อจำกัด
- คนติด label มีคนเดียว (ผ่าน AI ช่วยคัดรอบแรก) ยังไม่ได้วัด inter-annotator agreement ถ้ามีเวลา ควรให้อีกคนติด label ซ้ำสัก 100 ข้อความแล้วคำนวณ Cohen's kappa
- คลาสหมิ่นประมาทในชุด test มีแค่ 15 ข้อความ ค่า F1 ของคลาสนี้จะแกว่งมาก ควรรายงานพร้อมจำนวนตัวอย่างเสมอ
- label ดูหมิ่นมาจาก label เดิมของ dataset (`neg`) โดยไม่ได้อ่านทุกแถว ผลตรวจแบบสุ่ม 200 แถว (`annotation/insult_audit.csv`) พบว่าเป็นคำดูหมิ่นจริงแค่ **40.5%**
  - ThaiToxicityTweet ถูก 91%, HateThaiSent 50%, ThaiCyberbullyingLGBT 33%
  - สาเหตุหลักคือ dataset LGBT ติด `neg` ให้ทุกข้อความที่มี "อิตุ๊ด/อีเกย์" รวมถึงตอนที่เพื่อนเรียกกันแบบสนิทสนม
